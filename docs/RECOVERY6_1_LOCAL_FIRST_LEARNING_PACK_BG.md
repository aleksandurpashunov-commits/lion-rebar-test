# Recovery 6.1 — Local-first Learning Pack

## Дефект

При реалния Windows тест `Край на сесията` върна `File is not a zip file`. Session Database беше запазена, но Learning Pack не беше публикуван. Причината беше архитектурна: каноничният ZIP се създаваше директно в откритата cloud review папка.

## Поправка

1. Каноничният Learning Pack се създава само в локалната Session Core директория.
2. ZIP-ът се проверява по структура, manifest, размер и SHA256 на всяко съдържание.
3. Локалният `LATEST` се създава атомарно и се проверява повторно.
4. Cloud копието е вторична best-effort операция с временен файл, fsync, ZIP и SHA проверка.
5. Cloud failure не отменя приключената сесия и не застрашава локалния пакет.

## Очакван Windows резултат

При успешна публикация UI показва локалния каноничен пакет и cloud копието.
При неуспешна публикация UI показва предупреждение, но сесията е приключена и локалният ZIP остава валиден.
