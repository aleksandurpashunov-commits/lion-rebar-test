# LION REBAR DESKTOP v0.1.37.1

## Причина

В v0.1.37 старият публикуван Engine v0.3.4 се зареждаше в новия модел преди
проверката на checksum-а. Новите семантични полета получаваха стойности по
подразбиране и така повторно сериализираното съдържание вече не съвпадаше с
оригиналното подписано JSON съдържание. Програмата правилно отказваше да
продължи при несъвпадение, но причината беше несъвместима проверка, а не
редактиран Engine.

## Корекция

- checksum-ът на публикуван Engine се проверява върху точното съдържание,
  прочетено от диска, без полето `content_sha256`;
- едва след успешната проверка JSON съдържанието се зарежда в актуалния модел;
- същият ред се използва при текущ Engine, конкретна публикувана версия и
  повторно активиране;
- реална промяна в публикувания файл продължава да се блокира.

## Обхват

Корекцията не променя:

- Engine v0.3.4, неговите форми или активния pointer;
- `TEST_HOLDOUT_01`, DXF файла или съществуващите решения;
- matcher логиката и резултатите от v0.1.37;
- забраната за автоматично одобрение.

## Проверка

Добавени са регресии за:

1. стар подписан Engine без новите семантични полета;
2. откриване на действително редактиран публикуван Engine.

## Инсталиране

1. Затвори LION REBAR DESKTOP.
2. Стартирай `UPDATE_LION_REBAR.bat`.
3. Избери `LION_REBAR_DESKTOP_v0.1.37.1_UPDATE.zip`.
4. Изчакай тестовете и реда `Active release: v0.1.37.1`.
5. Стартирай програмата и отвори същия `working\project.json`.
