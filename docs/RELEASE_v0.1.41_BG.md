# LION REBAR DESKTOP v0.1.41

Тази версия подобрява matcher-а върху реалния `TEST_HOLDOUT_01`, без да
увеличава безконтролно дистанции и допуски.

## Резултат върху 629 реални позиции

- намерен геометричен кандидат: 587 (93,3%);
- силно разпознати F006: 33 → 93;
- позиции за ръчен преглед: 175 → 115;
- запазени стари одобрения: 288/288;
- уверено разместени стари връзки: 0;
- F019 намира `8N10x406` с геометрия 50+286+70 cm.

## Правила за безопасност

- Извитата ос на F006 доказва формата, но не приема автоматично производствената
  разгъната дължина.
- Форма от повтарящи се аналози се извежда само при минимум три отделни и
  единодушни реални геометрии със същия надпис.
- Това извеждане не създава DXF връзка и позицията остава
  `НЯМА КАНДИДАТ`, докато локалната геометрия не бъде доказана.
- Реално използваната Engine версия се записва във всеки нов batch JSON.
