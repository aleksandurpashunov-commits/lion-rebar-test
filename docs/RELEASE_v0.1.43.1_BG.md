# LION REBAR DESKTOP v0.1.43.1

## Причина и поправка

В `v0.1.43` параметърът `engine_metadata` е деклариран по погрешка в
`count_batch_annotations()`, но е подаван към `build_batch_geometry_report()`.
Hotfix-ът премества параметъра в правилната функция, запазва Engine
проследимостта в JSON отчета и добавя регресионен тест с генериран ZIP отчет.
